# Pulse V2 — Real Human Relay

Pulse V2 turns the Relay from a shareable URL experiment into an in-app human handoff loop.

- `START A PULSE` creates a waiting Relay.
- `JOIN A PULSE` claims the oldest waiting Relay.
- Each participant gets one constrained micro-action rather than a blank writing box.
- Supabase stores the Relay and atomically claims turns.
- Three human moves produce a final result.

Visual direction: Swiss structure with a futuristic signal accent — strict grid, large type, thin rules, monochrome base, and orange as the single active signal.
