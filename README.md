# Pulse V0.1

Pulse is a world-discovery experiment: one tap reveals one thing you probably did not know.

## V0.1
- Pulse button
- Discovery card
- Next Pulse
- Save / Collection with localStorage
- Responsive premium visual language
- Static discovery dataset

## Intentionally excluded
- Authentication
- Database
- LIVE PULSE
- AI generation
- Social feed
- Analytics backend

The first hypothesis is simple: **does the user want to press Pulse again?**

## Run locally

```bash
npm install
npm run dev
```
